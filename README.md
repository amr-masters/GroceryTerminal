# Grocery Terminal

This is an ESP32 CYD project to provide a simple terminal for family to select groceries and household items they need so I can have them delivered to their home.

It provides a simple interface with buttons for different categories and items within categories. Selections are added to a list which can be reviewed, edited, and sent (or cleared). It uses [ntfy.sh](https://ntfy.sh/) for communication. You can set the WIFI SSID, Password, ntfy server and topic.

 (I used Hosyond ESP32-S3 Touchscreen Module, 2.8" 240x320 IPS LCD EPS32 Display with WiFi Bluetooth Capacitive Touch Screen for Arduino IoT Projects ordered from Amazon: https://a.co/d/0h25gliH) and [this case](https://www.printables.com/model/1889593-capacitive-cyd-case-with-battery-and-speaker) (note, the speaker mount did not fit the provided speaker and I did not have good luck with the heat set inserts and just taped things in place).
